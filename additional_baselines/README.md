# Additional fairness baselines

This package supplies shared candidate artifacts, CPFair/P-MMF reranking,
IFairLRS RR/RW, GRID continuations, encoder SPRINT, validation tuning and activity
diagnostics. It is installed by the parent project's editable installation.

Read [fairness workflows](../docs/fairness.md),
[experiment preparation](../docs/experiments.md), and
[metrics/provenance](../docs/reproducibility.md). Run
`python -m additional_baselines --help` for the available commands.
Use explicit source export/data paths for new experiments. Historical default
artifact namespaces exist only as compatibility helpers; their generated files
are not shipped. The parent README includes a synthetic local example.
